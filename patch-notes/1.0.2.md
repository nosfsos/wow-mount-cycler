# Flying Mount Cycler 1.0.2

Bug-fix release: the no-repeat cycle now persists correctly across logins and reloads.

## Highlights

- Fixes the cycle resetting to full on every login. The remaining-mount queue is now preserved between sessions and only resets when the cycle finishes or `/fmount reset` is used.
- Defers mount-journal sync from `ADDON_LOADED` to `PLAYER_LOGIN`, ensuring favorite and collection data is fully available before the cycle state is reconciled.
- Adds a defensive guard in the cycle-sync logic so an empty mount-journal response can no longer wipe saved cycle progress.

## Notes

- Targets WoW Retail/mainline clients.
- SavedVariables continue to use `FlyingMountCyclerDB` (account-wide).
