# Flying Mount Cycler 1.0.0

Initial stable release of Flying Mount Cycler for WoW Retail.

## Highlights

- Adds no-repeat mount cycling with separate `flying`, `ground`, and `any` favorite pools.
- Auto-selects pool by zone flyability, with options to override behavior in settings.
- Supports skyriding-family mounts as an optional part of the flying pool.
- Includes slash commands for summon, reset, refresh, status, debug, and config actions.
- Adds an Addon Compartment entry with left-click settings and right-click summon behavior.
- Provides a full in-game settings panel under Esc > Options > AddOns > Flying Mount Cycler.

## Notes

- Targets WoW Retail/mainline clients.
- SavedVariables use `FlyingMountCyclerDB` (account-wide).
