# Flying Mount Cycler 1.0.3

Compatibility update for WoW Retail / Midnight `12.0.5`.

## Highlights

- Updates the addon TOC to target the current Midnight `12.0.5` interface version directly.
- Refreshes addon metadata so the in-game AddOns list clearly shows the addon as `12.0.5`-ready.
- Documents the Midnight compatibility pass in the project README, noting that Blizzard's current addon restrictions are combat-focused and do not affect this mount-cycling workflow.

## Notes

- Verified against Blizzard's published Midnight addon guidance and current `12.0.5` content update announcements.
- No mount-selection logic changes were required for this release; the addon continues to use supported Retail mount journal and settings APIs.
- SavedVariables continue to use `FlyingMountCyclerDB` (account-wide).
