# Flying Mount Cycler 1.0.1

Quality-of-life update focused on skip controls, lock timer customization, and clearer status output.

## Highlights

- Adds `/fmount skip` and `/fmount next` to force a new mount immediately (bypasses the current lock once).
- Adds a **Skip / Next Mount** button in **Cycle Tools** for the same in-UI behavior.
- Expands lock duration presets and adds a custom lock duration input (1-1440 minutes).
- Updates lock remaining display to show minutes above 60 seconds, then seconds at 60 seconds or below.
- Improves README command and timer documentation.

## Notes

- Targets WoW Retail/mainline clients.
- SavedVariables continue to use `FlyingMountCyclerDB` (account-wide).
